## What this is

The ToIP **Decentralized Trust Graph** 🕸️ published its Credentials Core Spec, and it turned out to name the
same things spellweb already graphs — VRC/VMC/VIC/VPC/VEC/VWC, the four DIDs, a two-faced trust registry — but
left the **ZK layer deliberately open**. That open layer is the DTG ZKP Task Force's charter, and it is where
our framework already lives. This dream cycle did two things: it **cohered our credential vocabulary to the
spec**, and it **contributed a harness runtime** — `07-trust-graph-formation` — that makes *how the graph
forms* runnable as an ⚔️⊥🧙 dream-agent cycle.

The spine, unchanged from the KG: **collision → edge → propagation. The trust graph grows one collision at a
time.** The runtime makes each arrow mechanical and names it on both sides of the mirror.

## Current state & open threads

**The forms spec (what a node/edge/growth *is*, matched both ways):**
- **Node** = a personhood-anchored member of a community. In the graph: `derives_identity_from` the Celestial
  Key ☀️⊥🌙; in the spec: an **M-DID** in a **VTC**, personhood via the **PHC** "one-membership-per-person"
  rule. The runtime `anchors_to` runtime 01's nullifier — one node per human per community.
- **Edge** = a **VRC** 🤝📜 `forged_by` a matching compression, `witnessed_by` mutual consent. In the spec:
  a VRC between two fresh **R-DIDs** (each party mints a new one per counterparty — no reuse, no correlation).
  The 🪢 City Key stays the glyph; the knot is non-transferable, earned by walking.
- **Growth** = `propagation` — two members of one VTC prove a path exists without revealing the members
  (community-anchored ZKP). Value still lives in the Gap ⿻: the most trust-paths cross there.

**The dream-agent cycle (the fold that grows the graph):**
- 🧙 **Mage** (`bnot`, proposer) proposes the smallest edge — a candidate VRC carrying each side's R-DID and
  consent.
- ⚔️ **Swordsman** (`neg`, prover) proves before signing: both endpoints personhood-anchored, no self-edge
  (self-Sybil refused), mutual consent, fresh R-DIDs, and — **across the Gap** — recomputes the VRC commitment
  rather than trusting the proposer.
- ⿻ **The Gap** holds them apart. `neg(bnot(x)) = succ(x)`: the graph advances by one edge only when a
  reduction is signed by a proof that did not collude with it. A bare proposal never touches the graph.
